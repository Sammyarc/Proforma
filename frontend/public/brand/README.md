# Proforma identity

The mark combines the letter P with a folded document: a clear reference to professional invoices, finished work, and forward progress. Forest green anchors it to the product; the lime fold adds a recognizable detail at small sizes.

- `proforma-mark.svg`: standalone scalable mark, used in navigation, authentication, workspace branding, and favicon.
- `proforma-logo.svg`: horizontal mark and wordmark lockup. The wordmark uses an explicit Arial/sans-serif fallback for portability.

Original vector artwork created for this product. The icon needs no external font or image service.
